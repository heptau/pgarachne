<h2>PgArachne Toolbar pour macOS</h2>
<p>Le <strong>PgArachne Toolbar</strong> est une application native professionnelle pour macOS conçue pour offrir une expérience de gestion sans effort de vos instances de passerelle JSON-RPC.</p>

<div class="status-badge" style="display: inline-block; background: #fff3cd; color: #856404; padding: 10px 15px; border-radius: 5px; margin-bottom: 20px; border: 1px solid #ffeeba;">
<strong>Statut :</strong> En préparation. Sortie prévue : <strong>2ème trimestre 2026</strong>.
</div>

<h3>Caractéristiques principales</h3>
<ul>
<li><strong>Gestion multi-serveurs :</strong> Démarrez, arrêtez et redémarrez plusieurs instances PgArachne à partir d'un seul menu.</li>
<li><strong>Changement de configuration :</strong> Basculez rapidement entre des environnements partagés ou des configurations de base de données locales.</li>
<li><strong>Surveillance en direct :</strong> Fenêtre intégrée pour les journaux en temps réel et les métriques de performance.</li>
<li><strong>Expérience native :</strong> Conçue spécifiquement pour macOS avec prise en charge du mode sombre et d'Apple Silicon.</li>
</ul>

<h3>Bientôt sur le Mac App Store</h3>
<p>L'application est en cours d'optimisation pour le Mac App Store afin de garantir une sécurité maximale et des mises à jour fluides.</p>
