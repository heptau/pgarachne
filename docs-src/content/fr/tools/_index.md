<section id="tools">
<h2>Outils</h2>
<p>PgArachne est soutenu par une variété d'outils conçus pour simplifier le développement, les tests et la gestion de vos API de base de données.</p>

<div class="tools-grid">
<div class="card">
<h3>PgArachne Explorer</h3>
<p>Une interface web puissante à fichier unique pour inspecter votre API, tester des fonctions et visualiser la documentation générée automatiquement. Elle fonctionne directement dans votre navigateur et est incluse dans le code source.</p>
<p><a href="api-explorer/" class="btn">En savoir plus sur l'Explorer</a></p>
</div>

<div class="card">
<h3>PgArachne Toolbar (macOS)</h3>
<p>Une application macOS native qui réside dans votre barre de menus. Elle vous permet de gérer plusieurs instances de PgArachne, de consulter les journaux en direct et de surveiller les métriques en un seul clic.</p>
<p><a href="macos-toolbar/" class="btn">Explorer les fonctionnalités du Toolbar</a></p>
</div>
</div>
