Métriques (Prometheus)

PgArachne exporte les métriques Prometheus sur un listener dédié aux métriques (par défaut 127.0.0.1:9090) via /metrics, incluant les métriques Go standard et :

  • pgarachne_http_requests_total, pgarachne_http_request_duration_seconds
  • pgarachne_auth_requests_total, pgarachne_login_attempts_total
  • pgarachne_jsonrpc_requests_total
  • pgarachne_sse_clients, pgarachne_sse_channels, pgarachne_sse_client_drops_total
  • pgarachne_sse_events_forwarded_total — événements PostgreSQL NOTIFY transmis aux clients SSE, avec la base de données comme label
  • pgarachne_sse_bytes_sent_total — octets écrits dans les flux de réponse SSE (payloads, heartbeats, préambule), avec la base de données comme label
  • pgarachne_sse_listen_errors_total — erreurs PostgreSQL LISTEN/connexion et événements de reconnexion, avec la base de données et le type d'événement comme labels. Une valeur non nulle mérite d'être investiguée — le hub abandonne tous les clients lors d'une reconnexion, ce qui provoque une brève interruption visible par les utilisateurs.
