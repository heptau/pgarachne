PgArachne est-il fait pour vous ?

PgArachne™ est un gateway backend prêt pour la production — d'un MVP solo à un système haute charge. Définissez une fonction SQL et votre endpoint API est immédiatement opérationnel. Aucun boilerplate, aucun service supplémentaire.

🚀 Zéro Boilerplate

Arrêtez d'écrire des contrôleurs CRUD répétitifs. Définissez une fonction SQL et votre endpoint API est prêt instantanément. Votre base de données est votre backend — PgArachne l'expose simplement de manière sécurisée.

🏢 Prêt pour la Production

Conçu pour gérer plus de 90 % des tâches backend standard (CRUD, validation, auth). Avec le pooling de connexions, les arrêts propres et les métriques Prometheus, il alimente les systèmes de production de manière fiable.

🧠 Support Natif MCP & IA

PgArachne expose un endpoint natif Model Context Protocol (MCP), pour que les clients IA comme Claude Desktop ou Cursor puissent découvrir et appeler vos fonctions PostgreSQL comme des outils — sans une seule ligne de code supplémentaire. L'API se documente également elle-même via des commentaires SQL pour les LLMs.

⚡ Notifications temps réel (SSE)

Événements en temps réel via HTTP standard avec support natif des navigateurs. Abonnez-vous aux canaux PostgreSQL NOTIFY directement depuis le client. Idéal pour les dashboards et mises à jour en direct sans WebSockets.

🔒 Sécurité Native Base de Données

Pas de tables utilisateurs séparées. L'authentification utilise de vrais rôles PostgreSQL et des JWT. Chaque requête s'exécute en tant qu'utilisateur authentifié via SET LOCAL ROLE, donc la Row-Level Security (RLS) fonctionne automatiquement.
