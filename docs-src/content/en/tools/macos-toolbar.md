<h2>PgArachne Toolbar for macOS</h2>
<p>The <strong>PgArachne Toolbar</strong> is a professional native application for macOS designed to provide an effortless management experience for your JSON-RPC gateway instances.</p>

<div class="status-badge" style="display: inline-block; background: #fff3cd; color: #856404; padding: 10px 15px; border-radius: 5px; margin-bottom: 20px; border: 1px solid #ffeeba;">
<strong>Status:</strong> Under development. Expected release: <strong>Q2 2026</strong>.
</div>

<h3>Key Features</h3>
<ul>
<li><strong>Multi-Server Management:</strong> Start, stop, and restart multiple PgArachne instances from a single menu.</li>
<li><strong>Configuration Switching:</strong> Quickly toggle between shared environments or local database configurations.</li>
<li><strong>Live Monitoring:</strong> Integrated window for real-time logs and performance metrics.</li>
<li><strong>Native Experience:</strong> Built specifically for macOS with support for dark mode and Apple Silicon.</li>
</ul>

<h3>Coming to the Mac App Store</h3>
<p>The application is being optimized for the Mac App Store to ensure the highest security and seamless updates.</p>
