Γρήγορη εκκίνηση

Αποκτήστε ένα λειτουργικό JSON-RPC API από τη βάση PostgreSQL σας σε λιγότερο από ένα λεπτό. Η βάση δεδομένων σας είναι το backend σας — χωρίς framework, χωρίς boilerplate.

1. Εγκατάσταση

Κατεβάστε ένα δυαδικό αρχείο

# macOS (Homebrew)
brew install heptau/tap/pgarachne

# ή κατεβάστε την τελευταία έκδοση για το λειτουργικό σας:
#   https://github.com/heptau/pgarachne/releases/latest

2. Ρυθμίστε τη βάση δεδομένων σας

Δημιουργήστε μια βάση και φορτώστε το σχήμα PgArachne:

createdb my_database
psql -d my_database -f sql/schema.sql

3. Διαμόρφωση και εκκίνηση

Δημιουργήστε ένα αρχείο pgarachne.env (ο διακομιστής το βρίσκει στον τρέχοντα κατάλογο):

DB_HOST=localhost
DB_PORT=5432
DB_USER=pgarachne
JWT_SECRET=$(openssl rand -hex 32)

Εκκινήστε τον διακομιστή:

./pgarachne

4. Ορίστε μια συνάρτηση

Στη βάση σας, δημιουργήστε έναν ρόλο και μια συνάρτηση. Το SQL σχόλιο της συνάρτησης την τεκμηριώνει για τα LLM.

CREATE ROLE demo_user WITH LOGIN PASSWORD 'user_password';
GRANT USAGE ON SCHEMA api TO demo_user;

CREATE OR REPLACE FUNCTION api.hello_world(payload jsonb)
RETURNS json LANGUAGE sql AS $$
    SELECT '"Hello World"'::json;
$$;
GRANT EXECUTE ON FUNCTION api.hello_world(jsonb) TO demo_user;

5. Καλέστε τη

Το API endpoint σας είναι ζωντανό:

curl -X POST http://localhost:8080/db/my_database/jsonrpc \
  -u demo_user:user_password \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"api.hello_world","params":{},"id":1}'
# → {"jsonrpc":"2.0","result":"Hello World","id":1}

6. Συνδέστε έναν AI πράκτορα (MCP)

Εκθέστε τις ίδιες συναρτήσεις στο Claude Desktop ή στο Cursor ως εργαλεία μέσω του MCP endpoint:

POST http://localhost:8080/db/my_database/mcp

Δείτε MCP (Model Context Protocol) για πλήρεις οδηγίες σύνδεσης.

Αυτό ήταν. Διαβάστε τον οδηγό Hello World για τη ροή αυθεντικοποίησης JWT, ή τη σύγκριση με το PostgREST για να κατανοήσετε πού ταιριάζει το PgArachne.
