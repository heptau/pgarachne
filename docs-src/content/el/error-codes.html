Κωδικοί Σφαλμάτων

Το PgArachne επιστρέφει τυπικά αντικείμενα σφαλμάτων JSON-RPC 2.0. Παρακάτω είναι οι συγκεκριμένοι κωδικοί που μπορεί να συναντήσετε:

Κωδικός Μήνυμα Σημασία
-32700 Parse error Ελήφθη μη έγκυρη JSON από τον server.
-32601 Method not found Η function δεν υπάρχει στο σχήμα.
-32602 Invalid params Τα arguments δεν ταιριάζουν με το signature της function.
-32001 Permission denied Ο τρέχων ρόλος χρήστη δεν έχει δικαιώματα εκτέλεσης της function (επίπεδο DB).
-32000 Internal Error Γενικό σφάλμα server (ελέγξτε τα logs).
Τρέχουσα συμπεριφορά: οι απαντήσεις runtime αντιστοιχίζονται κυρίως σε HTTP status codes με ένα JSON-RPC error message. Ο custom κωδικός JSON-RPC -32001 χρησιμοποιείται για άρνηση ρόλου/δικαιώματος.
