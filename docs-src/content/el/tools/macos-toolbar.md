<h2>PgArachne Toolbar για macOS</h2>
<p>Το <strong>PgArachne Toolbar</strong> είναι μια επαγγελματική εγγενής εφαρμογή για macOS σχεδιασμένη να προσφέρει μια απρόσκοπτη εμπειρία διαχείρισης για τις εγκαταστάσεις της πύλης JSON-RPC σας.</p>

<div class="status-badge" style="display: inline-block; background: #fff3cd; color: #856404; padding: 10px 15px; border-radius: 5px; margin-bottom: 20px; border: 1px solid #ffeeba;">
<strong>Κατάσταση:</strong> Υπό ανάπτυξη. Αναμενόμενη κυκλοφορία: <strong>Q2 2026</strong>.
</div>

<h3>Βασικές Λειτουργίες</h3>
<ul>
<li><strong>Διαχείριση Πολλαπλών Servers:</strong> Εκκίνηση, διακοπή, και επανεκκίνηση πολλαπλών εγκαταστάσεων PgArachne από ένα μόνο μενού.</li>
<li><strong>Εναλλαγή Ρυθμίσεων:</strong> Ταχεία εναλλαγή μεταξύ κοινών περιβαλλόντων ή τοπικών ρυθμίσεων βάσης δεδομένων.</li>
<li><strong>Ζωντανή Παρακολούθηση:</strong> Ενσωματωμένο παράθυρο για logs σε πραγματικό χρόνο και μετρήσεις απόδοσης.</li>
<li><strong>Εγγενής Εμπειρία:</strong> Χτισμένο ειδικά για macOS με υποστήριξη dark mode και Apple Silicon.</li>
</ul>

<h3>Έρχεται στο Mac App Store</h3>
<p>Η εφαρμογή βελτιστοποιείται για το Mac App Store ώστε να διασφαλίζεται η μέγιστη ασφάλεια και απρόσκοπτες ενημερώσεις.</p>
