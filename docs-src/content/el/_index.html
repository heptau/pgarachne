--- title: "PgArachne" description: "PgArachne – Στιγμιαίο PostgreSQL API" ---

Είναι το PgArachne κατάλληλο για εσάς;

Το PgArachne™ είναι μια production-grade backend gateway — από ένα μόνο MVP έως ένα σύστημα παραγωγής με υψηλή επισκεψιμότητα. Ορίστε μια SQL function και το API endpoint σας είναι έτοιμο. Χωρίς boilerplate, χωρίς επιπλέον υπηρεσίες.

🚀 Μηδενικό Boilerplate

Σταματήστε να γράφετε επαναλαμβανόμενους CRUD controllers. Ορίστε μια SQL function και το API endpoint σας είναι αμέσως έτοιμο. Η βάση δεδομένων σας είναι το backend σας — το PgArachne απλώς το εκθέτει με ασφάλεια.

🏢 Έτοιμο για Παραγωγή

Σχεδιασμένο να καλύπτει πάνω από το 90% των συνηθισμένων backend εργασιών (CRUD, validation, auth). Με connection pooling, graceful shutdowns και μετρικές Prometheus, τροφοδοτεί συστήματα παραγωγής με αξιοπιστία.

🧠 Native Υποστήριξη MCP & AI

Το PgArachne εκθέτει ένα native endpoint Model Context Protocol (MCP), ώστε AI clients όπως το Claude Desktop ή το Cursor να μπορούν να ανακαλύψουν και να καλέσουν τις PostgreSQL functions σας ως εργαλεία — χωρίς επιπλέον κώδικα. Το API τεκμηριώνεται επίσης αυτόματα μέσω SQL comments για κατανάλωση από LLM.

⚡ Ειδοποιήσεις Πραγματικού Χρόνου (SSE)

Κάντε streaming events σε πραγματικό χρόνο μέσω τυπικού HTTP με ενσωματωμένη υποστήριξη browser. Κάντε subscribe στα κανάλια NOTIFY της PostgreSQL απευθείας από τον client. Ιδανικό για dashboards και live ενημερώσεις χωρίς WebSockets.

🔒 Ασφάλεια Ενσωματωμένη στη Βάση Δεδομένων

Χωρίς ξεχωριστούς πίνακες χρηστών. Η authentication χρησιμοποιεί πραγματικούς ρόλους PostgreSQL και JWT. Κάθε request εκτελείται ως ο αυθεντικοποιημένος χρήστης μέσω SET LOCAL ROLE, οπότε το Row-Level Security (RLS) λειτουργεί αυτόματα.
