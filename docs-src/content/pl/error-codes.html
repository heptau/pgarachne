Kody błędów

PgArachne zwraca standardowe obiekty błędów JSON-RPC 2.0. Poniżej znajdują się konkretne kody, które możesz napotkać:

Kod Komunikat Znaczenie
-32700 Parse error Serwer otrzymał nieprawidłowy JSON.
-32601 Method not found Funkcja nie istnieje w schemacie.
-32602 Invalid params Argumenty nie odpowiadają sygnaturze funkcji.
-32001 Permission denied Aktualna rola użytkownika nie ma uprawnień do wykonania funkcji (na poziomie bazy danych).
-32000 Internal Error Ogólny błąd serwera (sprawdź logi).
Aktualne zachowanie: odpowiedzi w czasie działania są mapowane głównie na kody statusu HTTP wraz z polem message błędu JSON-RPC. Niestandardowy kod JSON-RPC -32001 jest używany przy odmowie roli/uprawnień.
