--- title: "PgArachne" description: "PgArachne – Natychmiastowe API dla PostgreSQL" ---

Czy PgArachne jest dla Ciebie?

PgArachne™ to backendowa brama gotowa do produkcji — od solowego MVP po system produkcyjny o dużym natężeniu ruchu. Zdefiniuj funkcję SQL, a Twój endpoint API jest gotowy. Bez boilerplate'u, bez dodatkowych usług.

🚀 Zero boilerplate'u

Przestań pisać powtarzalne kontrolery CRUD. Zdefiniuj funkcję SQL i Twój endpoint API jest gotowy natychmiast. Twoja baza danych jest Twoim backendem — PgArachne tylko bezpiecznie ją udostępnia.

🏢 Gotowe do produkcji

Zaprojektowane tak, by obsłużyć ponad 90% standardowych zadań backendowych (CRUD, walidacja, autoryzacja). Dzięki poolowaniu połączeń, kontrolowanemu zamykaniu i metrykom Prometheus napędza produkcyjne systemy w sposób niezawodny.

🧠 Natywne wsparcie MCP i AI

PgArachne udostępnia natywny endpoint Model Context Protocol (MCP), dzięki czemu klienci AI, tacy jak Claude Desktop czy Cursor, mogą odkrywać i wywoływać Twoje funkcje PostgreSQL jako narzędzia — bez ani jednej linii dodatkowego kodu. API dokumentuje się również samo za pomocą komentarzy SQL przeznaczonych do odczytu przez LLM.

⚡ Powiadomienia w czasie rzeczywistym (SSE)

Strumieniuj zdarzenia w czasie rzeczywistym przez standardowe HTTP z natywnym wsparciem w przeglądarce. Subskrybuj kanały PostgreSQL NOTIFY bezpośrednio z klienta. Świetne rozwiązanie do dashboardów i aktualizacji na żywo bez WebSocketów.

🔒 Bezpieczeństwo natywne dla bazy danych

Żadnych osobnych tabel użytkowników. Autoryzacja wykorzystuje rzeczywiste role PostgreSQL i JWT. Każde żądanie jest wykonywane jako uwierzytelniony użytkownik za pomocą SET LOCAL ROLE, dzięki czemu Row-Level Security (RLS) działa automatycznie.

🏛️ Decyzje projektowe

Czemu JSON-RPC? Czemu Go? Czemu SSE? Czemu MCP jako warstwa translacji? Przeczytaj nasze szczegółowe decyzje architektoniczne, aby zrozumieć, co napędza silnik PgArachne.

🤖 Indeks przyjazny dla LLM

Agenci AI i przeglądarki LLM mogą przeczytać cały projekt w jednym pliku: llms.txt to czytelny maszynowo punkt wejścia (format llmstxt.org), który dokładnie mówi modelom, jak PgArachne może służyć jako backend.
