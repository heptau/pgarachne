--- title: "PgArachne" description: "PgArachne – миттєвий PostgreSQL API" ---

Чи підходить PgArachne саме вам?

PgArachne™ — це промислового рівня backend-шлюз — від одноосібного MVP до високонавантаженої продакшн-системи. Визначте SQL-функцію, і ваш API-ендпоінт готовий. Без boilerplate, без додаткових сервісів.

🚀 Нуль boilerplate

Перестаньте писати повторювані CRUD-контролери. Визначте SQL-функцію, і ваш API-ендпоінт готовий миттєво. Ваша база даних і є вашим backend — PgArachne просто безпечно її надає.

🏢 Готовий до продакшну

Розроблений для обробки понад 90% стандартних backend-завдань (CRUD, валідація, авторизація). З пулінгом з'єднань, плавним завершенням роботи (graceful shutdown) та метриками Prometheus він надійно живить продакшн-системи.

🧠 Нативна підтримка MCP та AI

PgArachne надає нативний ендпоінт Model Context Protocol (MCP), тож AI-клієнти, такі як Claude Desktop або Cursor, можуть виявляти та викликати ваші функції PostgreSQL як інструменти — без жодного додаткового коду. API також самодокументується за допомогою SQL-коментарів для споживання LLM.

⚡ Сповіщення в реальному часі (SSE)

Транслюйте події в реальному часі через стандартний HTTP із вбудованою підтримкою в браузерах. Підписуйтеся на канали PostgreSQL NOTIFY безпосередньо з клієнта. Чудово підходить для дашбордів та живих оновлень без WebSocket.

🔒 Безпека на рівні бази даних

Жодних окремих таблиць користувачів. Автентифікація використовує справжні ролі PostgreSQL та JWT. Кожен запит виконується як автентифікований користувач через SET LOCAL ROLE, тож Row-Level Security (RLS) працює автоматично.

🏛️ Архітектурні рішення

Чому JSON-RPC? Чому Go? Чому SSE? Чому MCP як рівень трансляції? Прочитайте наші детальні архітектурні рішення, щоб зрозуміти механізм під капотом.

🤖 Індекс, зручний для LLM

AI-агенти та LLM-краулери можуть прочитати весь проєкт в одному файлі: llms.txt — це машинозчитувана точка входу (формат llmstxt.org), яка точно пояснює моделям, як PgArachne може служити бекендом.
