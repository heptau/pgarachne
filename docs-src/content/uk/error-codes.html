Коди помилок

PgArachne повертає стандартні об'єкти помилок JSON-RPC 2.0. Нижче наведені специфічні коди, з якими ви можете зіткнутися:

Код Повідомлення Значення
-32700 Parse error Сервер отримав недійсний JSON.
-32601 Method not found Функція не існує у схемі.
-32602 Invalid params Аргументи не відповідають сигнатурі функції.
-32001 Permission denied Поточна роль користувача не має прав на виконання функції (на рівні БД).
-32000 Internal Error Загальна помилка сервера (перевірте логи).
Поточна поведінка: відповіді runtime здебільшого мапляться на HTTP статус-коди з полем JSON-RPC message. Власний код JSON-RPC -32001 використовується для відмови через роль/права доступу.

Відповідність HTTP статусів

HTTPТипове повідомленняКоли виникає
400Invalid JSON request / Invalid function nameНекоректний payload запиту або формат методу.
401Authorization header is missing / Invalid or expired tokenВідсутня або недійсна автентифікація.
403Permission denied for the specified roleНе вдалося виконати SET LOCAL ROLE (-32001).
404Function does not existЦільовий метод відсутній.
429Too many login attemptsПеревищено ліміт спроб входу.
500Function call failed / Transaction commit failedПомилка виконання або commit.
503Database connection failed / Database unavailableТимчасова недоступність бази даних або listener.
