<h2>PgArachne Toolbar для macOS</h2>
<p><strong>PgArachne Toolbar</strong> — це професійний рідний застосунок для macOS, розроблений для забезпечення легкого керування вашими екземплярами JSON-RPC gateway.</p>

<div class="status-badge" style="display: inline-block; background: #fff3cd; color: #856404; padding: 10px 15px; border-radius: 5px; margin-bottom: 20px; border: 1px solid #ffeeba;">
<strong>Статус:</strong> У розробці. Очікуваний реліз: <strong>2 квартал 2026</strong>.
</div>

<h3>Основні можливості</h3>
<ul>
<li><strong>Керування кількома серверами:</strong> Запускайте, зупиняйте та перезапускайте кілька екземплярів PgArachne з одного меню.</li>
<li><strong>Перемикання конфігурацій:</strong> Швидко перемикайтеся між спільними середовищами або локальними конфігураціями бази даних.</li>
<li><strong>Живий моніторинг:</strong> Вбудоване вікно для логів і метрик продуктивності в реальному часі.</li>
<li><strong>Рідний досвід:</strong> Створений спеціально для macOS з підтримкою темного режиму та Apple Silicon.</li>
</ul>

<h3>Незабаром у Mac App Store</h3>
<p>Застосунок оптимізується для Mac App Store, щоб забезпечити найвищий рівень безпеки та безперебійні оновлення.</p>
