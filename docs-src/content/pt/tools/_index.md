<h2>Ferramentas</h2>
<p>O PgArachne é apoiado por uma variedade de ferramentas projetadas para simplificar o desenvolvimento, testes e gerenciamento de suas APIs de banco de dados.</p>

<div class="tools-grid">
<div class="card">
<h3>PgArachne Explorer</h3>
<p>Uma poderosa interface web de arquivo único para inspecionar sua API, testar funções e visualizar a documentação gerada automaticamente. Funciona diretamente no seu navegador e está incluída no código-fonte.</p>
<p><a href="api-explorer/" class="btn">Saiba mais sobre o Explorer</a></p>
</div>

<div class="card">
<h3>PgArachne Toolbar (macOS)</h3>
<p>Um aplicativo nativo para macOS que reside na sua barra de menus. Ele permite gerenciar múltiplas instâncias do PgArachne, visualizar logs em tempo real e monitorar métricas com um único clique.</p>
<p><a href="macos-toolbar/" class="btn">Explorar recursos do Toolbar</a></p>
</div>
</div>
