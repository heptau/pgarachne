<h2>PgArachne Toolbar para macOS</h2>
<p>O <strong>PgArachne Toolbar</strong> é um aplicativo nativo profissional para macOS projetado para oferecer uma experiência de gerenciamento sem esforço para suas instâncias de gateway JSON-RPC.</p>

<div class="status-badge" style="display: inline-block; background: #fff3cd; color: #856404; padding: 10px 15px; border-radius: 5px; margin-bottom: 20px; border: 1px solid #ffeeba;">
<strong>Status:</strong> Em preparação. Lançamento previsto: <strong>2º trimestre de 2026</strong>.
</div>

<h3>Principais Recursos</h3>
<ul>
<li><strong>Gerenciamento Multi-Servidor:</strong> Inicie, pare e reinicie várias instâncias do PgArachne a partir de um único menu.</li>
<li><strong>Alternância de Configuração:</strong> Alterne rapidamente entre ambientes compartilhados ou configurações de banco de dados locais.</li>
<li><strong>Monitoramento em Tempo Real:</strong> Janela integrada para logs em tempo real e métricas de desempenho.</li>
<li><strong>Experiência Nativa:</strong> Construído especificamente para macOS com suporte ao modo escuro e Apple Silicon.</li>
</ul>

<h3>Em breve na Mac App Store</h3>
<p>O aplicativo está sendo otimizado para a Mac App Store para garantir a máxima segurança e atualizações perfeitas.</p>
