Métricas (Prometheus)

PgArachne exporta métricas Prometheus em um listener dedicado de métricas (padrão 127.0.0.1:9090) em /metrics, incluindo métricas padrão do Go e:

  • pgarachne_http_requests_total, pgarachne_http_request_duration_seconds
  • pgarachne_auth_requests_total, pgarachne_login_attempts_total
  • pgarachne_jsonrpc_requests_total
  • pgarachne_sse_clients, pgarachne_sse_channels, pgarachne_sse_client_drops_total
  • pgarachne_sse_events_forwarded_total — eventos NOTIFY do PostgreSQL despachados para clientes SSE, com rótulo de banco de dados
  • pgarachne_sse_bytes_sent_total — bytes escritos nos streams de resposta SSE (payloads, heartbeats, preâmbulo), com rótulo de banco de dados
  • pgarachne_sse_listen_errors_total — erros de LISTEN/conexão do PostgreSQL e eventos de reconexão, com rótulo de banco de dados e tipo de evento. Um valor diferente de zero merece investigação — o hub descarta todos os clientes na reconexão, então os usuários percebem uma breve interrupção.
