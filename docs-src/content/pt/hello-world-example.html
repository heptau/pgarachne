Exemplo Hello World

Vamos criar um endpoint simples de API associado a um usuário.

1. Criar Usuário e Função

No seu banco de dados (meu_banco):

-- 1. Crie um usuário que fará login na API
CREATE ROLE demo_user WITH LOGIN PASSWORD 'user_password';
GRANT USAGE ON SCHEMA api TO demo_user;

-- 2. Crie a função Hello World
-- Entrada: jsonb vazio, Saída: json
CREATE OR REPLACE FUNCTION api.hello_world(payload jsonb)
RETURNS json
LANGUAGE sql
AS $$
    SELECT '"Hello World"'::json;
$$;

-- 3. Conceda permissão ao usuário
GRANT EXECUTE ON FUNCTION api.hello_world(jsonb) TO demo_user;

Escolha a forma de autenticação

  • Opção A — Fluxo de token JWT: requer um passo adicional de SQL (GRANT demo_user TO pgarachne) e a obtenção de um token antes de chamar a função. Recomendado para aplicações com múltiplos utilizadores.
  • Opção B — Credenciais diretas: envie utilizador e senha diretamente via HTTP Basic Auth. Nenhum GRANT … TO pgarachne é necessário. Ideal para desenvolvimento e scripts internos.

Opção A: Fluxo de Token JWT

A1. Configurar privilégios do proxy

Permita que o PgArachne possa alternar para demo_user:

-- Permita que o PgArachne (usuário do sistema) possa alternar para demo_user
GRANT demo_user TO pgarachne;

A2. Obter token JWT via API

Use o método JSON-RPC get_jwt para obter um token JWT:

curl -X POST http://localhost:8080/db/my_database/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"get_jwt","params":{"login":"demo_user","password":"user_password"},"id":1}'

Resposta:

{"jsonrpc":"2.0","result":{"token":"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."},"id":1}

A3. Chamar a Função com Bearer Token

Use o token para chamar a função hello_world:

export TOKEN="SEU_TOKEN_JWT_AQUI"

curl -X POST http://localhost:8080/db/my_database/jsonrpc \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "api.hello_world", "params": {}, "id": 1}'

Resposta:

{"jsonrpc": "2.0", "result": "Hello World", "id": 1}

Opção B: Credenciais Diretas (Basic Auth)

Não é necessário executar nenhum passo adicional de SQL. Envie as credenciais diretamente no cabeçalho da requisição usando a flag -u do curl:

curl -u demo_user:user_password \
  -X POST http://localhost:8080/db/my_database/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "api.hello_world", "params": {}, "id": 1}'

Resposta:

{"jsonrpc": "2.0", "result": "Hello World", "id": 1}

O PgArachne conecta-se diretamente ao PostgreSQL como demo_user — nenhum SET LOCAL ROLE é executado e nenhum GRANT demo_user TO pgarachne é necessário. Consulte Segurança e Autenticação para uma comparação completa de todos os métodos suportados.
