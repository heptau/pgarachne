<h2>PgArachne Toolbar pro macOS</h2>
<p><strong>PgArachne Toolbar</strong> je profesionální nativní aplikace pro macOS navržená pro snadnou správu vašich JSON-RPC gateway instancí.</p>

<div class="status-badge" style="display: inline-block; background: #fff3cd; color: #856404; padding: 10px 15px; border-radius: 5px; margin-bottom: 20px; border: 1px solid #ffeeba;">
<strong>Stav:</strong> V přípravě. Předpokládané vydání: <strong>2. kvartál 2026</strong>.
</div>

<h3>Klíčové funkce</h3>
<ul>
<li><strong>Správa více serverů:</strong> Spouštějte, zastavujte a restartujte více instancí PgArachne z jednoho menu.</li>
<li><strong>Změna konfigurace:</strong> Rychle přepínejte mezi sdílenými prostředími nebo lokálními databázemi.</li>
<li><strong>Živé monitorování:</strong> Integrované okno pro sledování logů a výkonnostních metrik v reálném čase.</li>
<li><strong>Nativní zážitek:</strong> Vyvinuto přímo pro macOS s podporou tmavého režimu a Apple Silicon.</li>
</ul>

<h3>Míří do Mac App Store</h3>
<p>Aplikace je optimalizována pro distribuci přes Mac App Store, aby byla zajištěna maximální bezpečnost a plynulé aktualizace.</p>
