Rychlý start

Rozběhněte JSON-RPC API z vaší PostgreSQL databáze za méně než minutu. Vaše databáze je váš backend — žádný framework, žádný boilerplate.

1. Instalace

Stáhněte si binárku

# macOS (Homebrew)
brew install heptau/tap/pgarachne

# nebo stáhněte nejnovější vydání pro váš OS:
#   https://github.com/heptau/pgarachne/releases/latest

2. Příprava databáze

Vytvořte databázi a načtěte schéma PgArachne:

createdb my_database
psql -d my_database -f sql/schema.sql

3. Konfigurace a spuštění

Vytvořte soubor pgarachne.env (server ho najde v aktuálním adresáři):

DB_HOST=localhost
DB_PORT=5432
DB_USER=pgarachne
JWT_SECRET=$(openssl rand -hex 32)

Spusťte server:

./pgarachne

4. Definujte funkci

V databázi vytvořte roli a funkci. SQL komentář funkce ji dokumentuje pro LLM.

CREATE ROLE demo_user WITH LOGIN PASSWORD 'user_password';
GRANT USAGE ON SCHEMA api TO demo_user;

CREATE OR REPLACE FUNCTION api.hello_world(payload jsonb)
RETURNS json LANGUAGE sql AS $$
    SELECT '"Hello World"'::json;
$$;
GRANT EXECUTE ON FUNCTION api.hello_world(jsonb) TO demo_user;

5. Zavolejte ji

Váš API endpoint je živý:

curl -X POST http://localhost:8080/db/my_database/jsonrpc \
  -u demo_user:user_password \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"api.hello_world","params":{},"id":1}'
# → {"jsonrpc":"2.0","result":"Hello World","id":1}

6. Připojte AI agenta (MCP)

Vystavte stejné funkce Claude Desktop nebo Cursoru jako nástroje přes MCP endpoint:

POST http://localhost:8080/db/my_database/mcp

Kompletní návod k připojení najdete na MCP (Model Context Protocol).

7. Získejte specifikaci OpenAPI (Swagger, Postman, codegen)

Každá vystavená funkce je také popsána jako dokument OpenAPI 3.1, filtrovaný podle toho, co smí autentizovaný volající zavolat:

curl http://localhost:8080/db/my_database/openapi.json \
  -u demo_user:user_password
# nebo jako YAML: .../openapi.yaml

Importujte URL přímo do Swagger UI, Postman nebo generátoru kódu OpenAPI. Každá metoda stále běží přes jediný JSON-RPC endpoint z kroku 5 — viz Architektonická rozhodnutí, kde je vysvětleno, proč specifikace uvádí cestu pro každou metodu bez odpovídající skutečné route.

To je vše. Přečtěte si Hello World návod pro JWT autentizaci, nebo srovnání s PostgREST pro pochopení, kam PgArachne zapadá.
