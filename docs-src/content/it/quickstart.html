Avvio rapido

Ottieni un'API JSON-RPC funzionante dal tuo database PostgreSQL in meno di un minuto. Il tuo database è il tuo backend — senza framework, senza boilerplate.

1. Installazione

Scarica un binario

# macOS (Homebrew)
brew install heptau/tap/pgarachne

# oppure scarica l'ultima release per il tuo OS:
#   https://github.com/heptau/pgarachne/releases/latest

2. Prepara il tuo database

Crea un database e carica lo schema PgArachne:

createdb my_database
psql -d my_database -f sql/schema.sql

3. Configura e avvia

Crea un file pgarachne.env (il server lo trova nella directory corrente):

DB_HOST=localhost
DB_PORT=5432
DB_USER=pgarachne
JWT_SECRET=$(openssl rand -hex 32)

Avvia il server:

./pgarachne

4. Definisci una funzione

Nel tuo database, crea un ruolo e una funzione. Il commento SQL della funzione la documenta per gli LLM.

CREATE ROLE demo_user WITH LOGIN PASSWORD 'user_password';
GRANT USAGE ON SCHEMA api TO demo_user;

CREATE OR REPLACE FUNCTION api.hello_world(payload jsonb)
RETURNS json LANGUAGE sql AS $$
    SELECT '"Hello World"'::json;
$$;
GRANT EXECUTE ON FUNCTION api.hello_world(jsonb) TO demo_user;

5. Chiamala

Il tuo endpoint API è attivo:

curl -X POST http://localhost:8080/db/my_database/jsonrpc \
  -u demo_user:user_password \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"api.hello_world","params":{},"id":1}'
# → {"jsonrpc":"2.0","result":"Hello World","id":1}

6. Connetti un agente IA (MCP)

Esponi le stesse funzioni a Claude Desktop o Cursor come strumenti tramite l'endpoint MCP:

POST http://localhost:8080/db/my_database/mcp

Vedi MCP (Model Context Protocol) per le istruzioni complete di connessione.

Fatto. Leggi la guida Hello World per il flusso di autenticazione JWT, o il confronto con PostgREST per capire dove si colloca PgArachne.
