Esempio Hello World

Creiamo un semplice endpoint API associato a un utente.

1. Creazione Utente e Funzione

Nel tuo database (my_database):

-- 1. Crea un utente che effettuerà il login sull'API
CREATE ROLE demo_user WITH LOGIN PASSWORD 'user_password';
GRANT USAGE ON SCHEMA api TO demo_user;

-- 2. Crea la funzione Hello World
-- Input: jsonb vuoto, Output: json
CREATE OR REPLACE FUNCTION api.hello_world(payload jsonb)
RETURNS json
LANGUAGE sql
AS $$
    SELECT '"Hello World"'::json;
$$;

-- 3. Concedi i permessi all'utente
GRANT EXECUTE ON FUNCTION api.hello_world(jsonb) TO demo_user;

Scelta del metodo di autenticazione

Esistono due modi per chiamare la funzione creata:

  • Opzione A — Flusso JWT: l'utente effettua il login e ottiene un token Bearer. Richiede un passo aggiuntivo di configurazione PostgreSQL (GRANT demo_user TO pgarachne).
  • Opzione B — Credenziali dirette: le credenziali PostgreSQL vengono trasmesse direttamente tramite HTTP Basic Auth. Nessun GRANT aggiuntivo richiesto. Ideale per sviluppo e servizi interni.

Opzione A: Flusso JWT

A1. Configurazione aggiuntiva PostgreSQL

Per il flusso JWT è necessario consentire a PgArachne di impersonare demo_user:

-- Permetti a PgArachne (utente di sistema) di impersonare demo_user
GRANT demo_user TO pgarachne;

A2. Ottenimento del token JWT

Usa il metodo JSON-RPC get_jwt per ottenere un token JWT:

curl -X POST http://localhost:8080/db/my_database/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"get_jwt","params":{"login":"demo_user","password":"user_password"},"id":1}'

Risposta:

{"jsonrpc":"2.0","result":{"token":"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."},"id":1}

A3. Chiamata della Funzione con Bearer Token

Usa il token per chiamare la funzione hello_world:

export TOKEN="IL_TUO_TOKEN_JWT_QUI"

curl -X POST http://localhost:8080/db/my_database/jsonrpc \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "api.hello_world", "params": {}, "id": 1}'

Risposta:

{"jsonrpc": "2.0", "result": "Hello World", "id": 1}

Opzione B: Credenziali dirette (Basic Auth)

Con le credenziali dirette non è necessario alcun GRANT aggiuntivo né la gestione dei token. PgArachne si connette direttamente a PostgreSQL come demo_user.

curl -u demo_user:user_password -X POST http://localhost:8080/db/my_database/jsonrpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "api.hello_world", "params": {}, "id": 1}'

Risposta:

{"jsonrpc": "2.0", "result": "Hello World", "id": 1}

Per ulteriori dettagli sul metodo delle credenziali dirette, consulta la pagina Sicurezza e Autenticazione.
