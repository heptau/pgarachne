<h2>Strumenti</h2>
<p>PgArachne è supportato da una varietà di strumenti progettati per semplificare lo sviluppo, il collaudo e la gestione delle tue API di database.</p>

<div class="tools-grid">
<div class="card">
<h3>PgArachne Explorer</h3>
<p>Una potente interfaccia web a file singolo per ispezionare le tue API, testare le funzioni e visualizzare la documentazione generata automaticamente. Funziona direttamente nel tuo browser ed è inclusa nel codice sorgente.</p>
<p><a href="api-explorer/" class="btn">Scopri di più sull'Explorer</a></p>
</div>

<div class="card">
<h3>PgArachne Toolbar (macOS)</h3>
<p>Un'applicazione nativa per macOS che risiede nella barra dei menu. Ti permette di gestire più istanze di PgArachne, visualizzare i log in tempo reale e monitorare le metriche con un solo clic.</p>
<p><a href="macos-toolbar/" class="btn">Esplora le funzionalità del Toolbar</a></p>
</div>
</div>
