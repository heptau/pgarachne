<h2>PgArachne Toolbar per macOS</h2>
<p>Il <strong>PgArachne Toolbar</strong> è un'applicazione nativa professionale per macOS progettata per offrire un'esperienza di gestione senza sforzo per le tue istanze di gateway JSON-RPC.</p>

<div class="status-badge" style="display: inline-block; background: #fff3cd; color: #856404; padding: 10px 15px; border-radius: 5px; margin-bottom: 20px; border: 1px solid #ffeeba;">
<strong>Stato:</strong> In preparazione. Uscita prevista: <strong>Q2 2026</strong>.
</div>

<h3>Caratteristiche principali</h3>
<ul>
<li><strong>Gestione multi-server:</strong> Avvia, arresta e riavvia più istanze di PgArachne da un unico menu.</li>
<li><strong>Cambio di configurazione:</strong> Passa rapidamente tra ambienti condivisi o configurazioni di database locali.</li>
<li><strong>Monitoraggio dal vivo:</strong> Finestra integrata per log in tempo reale e metriche di performance.</li>
<li><strong>Esperienza nativa:</strong> Costruita specificamente per macOS con supporto per la modalità scura e Apple Silicon.</li>
</ul>

<h3>In arrivo sul Mac App Store</h3>
<p>L'applicazione è in fase di ottimizzazione per il Mac App Store per garantire la massima sicurezza e aggiornamenti fluidi.</p>
