<h2>Herramientas</h2>
<p>PgArachne cuenta con una variedad de herramientas diseñadas para simplificar el desarrollo, las pruebas y la gestión de sus APIs de base de datos.</p>

<div class="tools-grid">
<div class="card">
<h3>PgArachne Explorer</h3>
<p>Una potente interfaz web de un solo archivo para inspeccionar su API, probar funciones y ver la documentación generada automáticamente. Funciona directamente en su navegador y está incluida en el código fuente.</p>
<p><a href="api-explorer/" class="btn">Más información sobre el Explorer</a></p>
</div>

<div class="card">
<h3>PgArachne Toolbar (macOS)</h3>
<p>Una aplicación nativa de macOS que reside en su barra de menús. Le permite gestionar múltiples instancias de PgArachne, ver registros en vivo y supervisar métricas con un solo clic.</p>
<p><a href="macos-toolbar/" class="btn">Explorar funciones del Toolbar</a></p>
</div>
</div>
