<h2>PgArachne Toolbar para macOS</h2>
<p>El <strong>PgArachne Toolbar</strong> es una aplicación nativa profesional para macOS diseñada para ofrecer una experiencia de gestión sin esfuerzo para sus instancias de gateway JSON-RPC.</p>

<div class="status-badge" style="display: inline-block; background: #fff3cd; color: #856404; padding: 10px 15px; border-radius: 5px; margin-bottom: 20px; border: 1px solid #ffeeba;">
<strong>Estado:</strong> En preparación. Lanzamiento previsto: <strong>Segundo Trimestre de 2026</strong>.
</div>

<h3>Características Principales</h3>
<ul>
<li><strong>Gestión de Múltiples Servidores:</strong> Inicie, detenga y reinicie múltiples instancias de PgArachne desde un solo menú.</li>
<li><strong>Cambio de Configuración:</strong> Alterne rápidamente entre entornos compartidos o configuraciones de bases de datos locales.</li>
<li><strong>Monitoreo en Vivo:</strong> Ventana integrada para registros en tiempo real y métricas de rendimiento.</li>
<li><strong>Experiencia Nativa:</strong> Construida específicamente para macOS con soporte para modo oscuro y Apple Silicon.</li>
</ul>

<h3>Próximamente en la Mac App Store</h3>
<p>La aplicación está siendo optimizada para la Mac App Store para garantizar la máxima seguridad y actualizaciones fluidas.</p>
