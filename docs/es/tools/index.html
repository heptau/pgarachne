Herramientas

PgArachne cuenta con una variedad de herramientas diseñadas para simplificar el desarrollo, las pruebas y la gestión de sus APIs de base de datos.

PgArachne Explorer

Una potente interfaz web de un solo archivo para inspeccionar su API, probar funciones y ver la documentación generada automáticamente. Funciona directamente en su navegador y está incluida en el código fuente.

Más información sobre el Explorer

PgArachne Toolbar (macOS)

Una aplicación nativa de macOS que reside en su barra de menús. Le permite gestionar múltiples instancias de PgArachne, ver registros en vivo y supervisar métricas con un solo clic.
