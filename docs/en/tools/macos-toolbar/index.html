PgArachne Toolbar for macOS

The PgArachne Toolbar is a professional native application for macOS designed to provide an effortless management experience for your JSON-RPC gateway instances.

Status: Under development. Expected release: Q2 2026.

Key Features

  • Multi-Server Management: Start, stop, and restart multiple PgArachne instances from a single menu.
  • Configuration Switching: Quickly toggle between shared environments or local database configurations.
  • Live Monitoring: Integrated window for real-time logs and performance metrics.
  • Native Experience: Built specifically for macOS with support for dark mode and Apple Silicon.

Coming to the Mac App Store

The application is being optimized for the Mac App Store to ensure the highest security and seamless updates.
