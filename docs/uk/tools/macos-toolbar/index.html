PgArachne Toolbar для macOS

PgArachne Toolbar — це професійний рідний застосунок для macOS, розроблений для забезпечення легкого керування вашими екземплярами JSON-RPC gateway.

Статус: У розробці. Очікуваний реліз: 2 квартал 2026.

Основні можливості

  • Керування кількома серверами: Запускайте, зупиняйте та перезапускайте кілька екземплярів PgArachne з одного меню.
  • Перемикання конфігурацій: Швидко перемикайтеся між спільними середовищами або локальними конфігураціями бази даних.
  • Живий моніторинг: Вбудоване вікно для логів і метрик продуктивності в реальному часі.
  • Рідний досвід: Створений спеціально для macOS з підтримкою темного режиму та Apple Silicon.

Незабаром у Mac App Store

Застосунок оптимізується для Mac App Store, щоб забезпечити найвищий рівень безпеки та безперебійні оновлення.
