Метрики (Prometheus)

PgArachne експортує метрики Prometheus на окремому listener метрик (за замовчуванням 127.0.0.1:9090) за адресою /metrics, включно зі стандартними метриками Go runtime та:

  • pgarachne_http_requests_total, pgarachne_http_request_duration_seconds
  • pgarachne_auth_requests_total, pgarachne_login_attempts_total
  • pgarachne_jsonrpc_requests_total
  • pgarachne_file_requests_total — виклики /file за методом і результатом (success, empty, error, duplicate)
  • pgarachne_sse_clients, pgarachne_sse_channels, pgarachne_sse_client_drops_total
  • pgarachne_sse_events_forwarded_total — події PostgreSQL NOTIFY, передані SSE-клієнтам, з міткою за базою даних
  • pgarachne_sse_bytes_sent_total — байти, записані в потоки відповідей SSE (payload, heartbeat, preamble), з міткою за базою даних
  • pgarachne_sse_listen_errors_total — помилки PostgreSQL LISTEN/з’єднання та події повторного підключення, з міткою за базою даних і типом події. Ненульове значення варте розслідування — при повторному підключенні hub відключає всіх клієнтів, тож користувачі помічають короткий збій.
