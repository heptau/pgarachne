PgArachne Toolbar per macOS

Il PgArachne Toolbar è un’applicazione nativa professionale per macOS progettata per offrire un’esperienza di gestione senza sforzo per le tue istanze di gateway JSON-RPC.

Stato: In preparazione. Uscita prevista: Q2 2026.

Caratteristiche principali

  • Gestione multi-server: Avvia, arresta e riavvia più istanze di PgArachne da un unico menu.
  • Cambio di configurazione: Passa rapidamente tra ambienti condivisi o configurazioni di database locali.
  • Monitoraggio dal vivo: Finestra integrata per log in tempo reale e metriche di performance.
  • Esperienza nativa: Costruita specificamente per macOS con supporto per la modalità scura e Apple Silicon.

In arrivo sul Mac App Store

L’applicazione è in fase di ottimizzazione per il Mac App Store per garantire la massima sicurezza e aggiornamenti fluidi.
