PgArachne Toolbar para macOS

O PgArachne Toolbar é um aplicativo nativo profissional para macOS projetado para oferecer uma experiência de gerenciamento sem esforço para suas instâncias de gateway JSON-RPC.

Status: Em preparação. Lançamento previsto: 2º trimestre de 2026.

Principais Recursos

  • Gerenciamento Multi-Servidor: Inicie, pare e reinicie várias instâncias do PgArachne a partir de um único menu.
  • Alternância de Configuração: Alterne rapidamente entre ambientes compartilhados ou configurações de banco de dados locais.
  • Monitoramento em Tempo Real: Janela integrada para logs em tempo real e métricas de desempenho.
  • Experiência Nativa: Construído especificamente para macOS com suporte ao modo escuro e Apple Silicon.

Em breve na Mac App Store

O aplicativo está sendo otimizado para a Mac App Store para garantir a máxima segurança e atualizações perfeitas.
