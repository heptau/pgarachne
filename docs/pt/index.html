O PgArachne é ideal para você?

O PgArachne™ é um gateway backend pronto para produção — de um MVP individual a um sistema de alto tráfego. Defina uma função SQL e o seu endpoint de API estará pronto instantaneamente. Sem boilerplate, sem serviços extras.

🚀 Sem Boilerplate

Pare de escrever controladores CRUD repetitivos. Defina uma função SQL e o seu endpoint de API estará pronto instantaneamente. Seu banco de dados é o seu backend — o PgArachne apenas o expõe com segurança.

🏢 Pronto para Produção

Projetado para lidar com mais de 90 % das tarefas de backend padrão (CRUD, validação, autenticação). Com pool de conexões, encerramento gracioso e métricas Prometheus, ele alimenta sistemas de produção de forma confiável.

🧠 Suporte Nativo a MCP e IA

O PgArachne expõe um endpoint nativo de Model Context Protocol (MCP), para que clientes de IA como Claude Desktop ou Cursor possam descobrir e chamar suas funções PostgreSQL como ferramentas — sem nenhuma linha de código extra. A API também se autodocumenta via comentários SQL para consumo por LLMs.

⚡ Notificações em tempo real (SSE)

Eventos em tempo real via HTTP padrão com suporte nativo do navegador. Assine canais PostgreSQL NOTIFY diretamente do cliente. Ideal para dashboards e atualizações ao vivo sem WebSockets.

🔒 Segurança Nativa do Banco de Dados

Sem tabelas de usuários separadas. A autenticação usa papéis PostgreSQL reais e JWT. Cada requisição é executada como o usuário autenticado via SET LOCAL ROLE, então a Row-Level Security (RLS) funciona automaticamente.
