PgArachne Toolbar pour macOS

Le PgArachne Toolbar est une application native professionnelle pour macOS conçue pour offrir une expérience de gestion sans effort de vos instances de passerelle JSON-RPC.

Statut : En préparation. Sortie prévue : 2ème trimestre 2026.

Caractéristiques principales

  • Gestion multi-serveurs : Démarrez, arrêtez et redémarrez plusieurs instances PgArachne à partir d’un seul menu.
  • Changement de configuration : Basculez rapidement entre des environnements partagés ou des configurations de base de données locales.
  • Surveillance en direct : Fenêtre intégrée pour les journaux en temps réel et les métriques de performance.
  • Expérience native : Conçue spécifiquement pour macOS avec prise en charge du mode sombre et d’Apple Silicon.

Bientôt sur le Mac App Store

L’application est en cours d’optimisation pour le Mac App Store afin de garantir une sécurité maximale et des mises à jour fluides.
