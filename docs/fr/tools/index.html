Outils

PgArachne est soutenu par une variété d’outils conçus pour simplifier le développement, les tests et la gestion de vos API de base de données.

PgArachne Explorer

Une interface web puissante à fichier unique pour inspecter votre API, tester des fonctions et visualiser la documentation générée automatiquement. Elle fonctionne directement dans votre navigateur et est incluse dans le code source.

En savoir plus sur l’Explorer

PgArachne Toolbar (macOS)

Une application macOS native qui réside dans votre barre de menus. Elle vous permet de gérer plusieurs instances de PgArachne, de consulter les journaux en direct et de surveiller les métriques en un seul clic.
